# Morelord Character Export 0.3.3

Export D&D 5e characters from Foundry VTT v14 for import into My Characters on the Morelord Gaming website with a free account.

## What Changed

### Improvements

- Exports include prepared item-use values alongside the character's source data and prepared sheet snapshot.
- Character Export now uses the standard Morelord release workflow for GitHub, Foundry VTT, and the Morelord Gaming release feed.
- Updated installation and usage documentation for My Characters and free website accounts.
- Added a versioned GM and player guide covering installation, export, website import, permissions, and troubleshooting, included in the module package and website documentation workflow.

## Compatibility

- Foundry VTT v14 only; D&D 5e minimum 4.0.0, verified 5.3.3.
- Requires a supported ApplicationV2 character sheet; legacy ApplicationV1 sheets are unsupported.
- Export format remains version 3. Morelord Core and an account connection are not required to export; a free Morelord Gaming website account is required to import into My Characters.
